# 第 25 课:Skill 中心与自定义分析模板

> **课时**: 20 分钟 | **难度**: ⭐⭐⭐ 中坚 | **前置**: 第 24 课

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,Skill 的输出不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 在「Skill 中心」找到、运行一个 Skill,理解它和普通分析的区别
- 用「Skill 生成」把自己的分析套路固化成一个可复用模板
- 知道什么时候用 Skill、什么时候用工作流、什么时候直接问助手

## 🤔 Skill 是什么

**Skill = 一个带专属提示词的深度分析模板。**

平台内置的分析(第 3、4 课)是"通用深度研究";Skill 是你给同一台多智能体引擎**换装上你自己的问题清单**。比如:

- 内置分析问:"这家公司基本面如何?"
- 一个"分红_DSP"Skill 问:"这家公司的分红可持续性:现金流覆盖、分红历史连续性、大股东持股与分红动机、行业分红周期位置——四项逐一评估"

同一个引擎,不同的**提问框架**——而分析质量的天花板,往往由提问框架决定。

## 📍 入口

侧边栏 →「**Skill 中心**」页(`/skills`),以及「Skill 生成」页(`/skills/generation/create`)。

## 🖱️ 核心操作

### 操作 1:从 Skill 中心运行一个 Skill

浏览 Skill 列表 → 选一个(看描述与标签,找贴合你需求的)→ 输入股票代码 → 运行。执行走你熟悉的分析队列,产出一份**按该 Skill 框架组织**的研究报告。

### 操作 2:用 Skill 生成做自己的模板

「Skill 生成」页把"我想让 AI 按什么套路分析"变成一个可用模板,流程:

1. **描述你的意图**:用自然语言写"我想要一个评估 XX 的分析模板,重点看 YY、ZZ"——不需要写提示词工程术语
2. **平台生成 Skill 定义**(会给出名称、适配的分析类型、提示词草稿)→ 你审读修改
3. **保存** → 出现在 Skill 中心,以后一键复用

**写好描述的诀窍**:把"你怎么人工做这件事"的步骤写出来。平台生成的模板质量,上限就是你描述的清晰度。

### 操作 3:给 Skill 喂"你的规则"

高级用法:把第 12、21、23 课沉淀的**个人规则库**(R1、R2……)写进 Skill 的评估维度:"请对照以下我的持仓规则逐条检查这只股票是否触碰:R1 单行业不超 40%……"。这样每份 Skill 报告都自带"和我的体系对照"这一节。

## 🧠 Skill vs 工作流 vs 助手:选择标准

| 工具 | 本质 | 什么时候用 |
|------|------|------------|
| 智能助理 | 对话,一次性 | 探索、临时问题、查数 |
| Skill | 单任务的分析模板 | "**一次深度分析**,但用我的框架" |
| 工作流 | 多节点流水线 | "**多步工序**,固定套路定时跑" |

记忆口诀:**问一次找助手,反复问同样问题做成 Skill,多步串起来才是工作流。**

## ❌ 常见错误

1. **Skill 描述写成"帮我分析这只股票"**——和内置分析没差别,浪费一次自定义;描述里必须有你自己的**独特框架**
2. **生成后不看草稿直接保存**——生成的是草稿,提示词里可能有你没意识到的遗漏;审读修改这一步省不得
3. **做个 Skill 只用一次**——Skill 的价值在复用,评估"这个分析框架我一年会跑多少次";一次性的问题直接问助手
4. **在 Skill 里写"给出买入建议"**——Skill 输出的是研究评估;把决策外包给模板,就不用学第 16 课的复盘了,因为你永远学不到东西
