# 第 24 课:AI 工作流架构师——把你的重复劳动做成流水线

> **课时**: 25 分钟 | **难度**: ⭐⭐⭐⭐ 高阶 | **前置**: 第 1-23 课

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,工作流的输出不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 看懂平台「AI 工作流」页的结构:节点、连线、执行语义
- 判断"这件事值不值得做成工作流"——不是所有重复都该自动化
- 组装一个三节点小工作流并跑通

## 🤔 什么是平台里的"工作流"

平台首页的「AI 工作流」是一个**可视化编排器**:把"调 AI 分析某股""查财务数据""写入记忆/生成报告"这类原子能力做成节点,用连线串成流程,一次定义,反复执行。

它和智能助理的区别:

| | 智能助理 | 工作流 |
|---|---------|--------|
| 交互方式 | 对话,即时 | 定义一次,定时/手动跑 |
| 适合 | 探索、临时问题 | **固定套路,反复执行** |
| 确定性 | 每次略有差异 | 结构固定,输出稳定 |

**判断标准**:这件事我描述过两次以上、并且第三次还会原样做吗?是 → 做工作流;否 → 用助手就够了,别过度工程。

## 📍 入口

侧边栏 →「**AI 工作流**」页。画布式界面:左侧节点面板,中间画布,顶部运行按钮。

## 🖱️ 核心概念:三类节点

一个工作流由任意三类节点组合:

### 1. 输入节点

工作流的起点:指定标的(固定代码,如"000858")或参数化(运行时传入)。**参数化输入**让一个工作流服务一类场景,而不是一只股票。

### 2. 执行节点

真正干活的部分,常用的几个:

- **分析节点**:对一个标的跑分析(可选深度/模板)
- **数据节点**:取行情、财务、新闻
- **AI 对话节点**:给大模型一段指令(提示词你自己写),对上文内容做总结/评分/生成

### 3. 输出节点

结果的落点:生成报告、写决策日志、生成摘要。**没有输出节点的工作流=跑了等于没跑**。

## 🖱️ 实操:组装"周报整理器"

目标:每周把自选池的三只重点票,自动出一份"周度摘要"。三节点:

1. **输入节点**:三个参数 `stock_1/2/3`(每周运行时传当周重点票)
2. **执行节点 A**:对每只股票取"本周行情+本周定时分析简报"(数据节点)
3. **执行节点 B**:**AI 节点**连在后面,提示词:

> "以下是三只股票本周的数据与分析简报。请输出一份周度摘要,每只股票三行:1) 本周表现一句话;2) 基本面/消息面变化;3) 是否触发我持仓规则中的条件(条件见附注)。用中文。"

4. **输出节点**:结果写为周报文档。

保存,命名"周报整理器",手动跑一次验证输出,然后**交给定时任务**(设置 → 定时任务,建议周五 19:00,和自选池同步衔接)。

## 🧠 工作流设计的四条军规

1. **节点只做一件事**——一个 AI 节点既摘要又评分又给建议,输出质量会全面平庸;拆成两个节点串联,各自提示词更短更准
2. **先手动跑通再定时**——定时任务里的失败是沉默的,手动跑一遍看过输出再挂定时
3. **AI 节点的提示词要带"输出格式"**——"输出一份摘要"不如"输出每只股票三行,行首以 1)2)3) 编号"——下游解析稳定靠格式约束
4. **失败的兜底**——工作流里数据节点可能因数据源抖动缺数,设计时在 AI 节点提示词里写明"若某只股票数据为空,输出'数据缺失',不要编造"

## ❌ 常见错误

1. **第一批就做 20 个节点的巨流**——先三个节点跑通,再加枝;巨流每次修改都是全量回归
2. **把"买卖决策"做成工作流**——工作流适合**整理/汇总/监控**,决策环节留给人;自动化的决策无法为结果负责
3. **提示词里塞股票名,不参数化**——三个几乎一样的工作流只差一个代码=维护三份;参数化输入节点只需一个
4. **从不看运行日志**——工作流每次运行的输出留在运行记录里,攒一个月不看,坏掉都不知道
