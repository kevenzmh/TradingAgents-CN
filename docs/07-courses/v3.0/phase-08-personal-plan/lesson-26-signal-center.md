# 第 26 课:信号链路与交易信号中心

> **课时**: 20 分钟 | **难度**: ⭐⭐⭐ 中坚 | **前置**: 第 1-25 课

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 信号不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 说清楚一条 AI 信号从产生到结算的完整链路(分析 → 判定 → 存档 → 结算)
- 配置好自己的**信号节奏**:定时分析、自选池同步、观察池轮转
- 把信号中心用作你的"决策入口仪表盘"而非"荐票机"

## 🤔 一条信号的完整一生

平台的信号不是拍脑袋的一句话,是一条可审计的链路:

```
定时/手动分析(多智能体+辩论)
        ↓
   方向性判定(BUY / SELL / 中性)+ 参考价(当日定格)
        ↓
   信号中心存档(带完整报告链接)
        ↓
   持续观察 → N 日后结算(方向、涨跌、相对基准 alpha,第 18 课)
```

两个设计要点:

1. **参考价当日定格**——信号的"考卷"在出手时印好,不存在事后修改
2. **中性也是有效输出**——"现阶段不下结论"本身是研判信息(第 18 课讲过中性占比怎么读)

## 📍 入口

侧边栏 →「**信号中心**」(交易/信号页签)。信号卡片:股票、方向、参考价、日期、来源报告、结算徽标。

## 🖱️ 核心操作:搭好自己的信号节奏

信号的统计价值需要**稳定供给**——有一搭没一搭地跑分析,样本永远不够。三件配置(多数在设置/定时任务页):

### 配置 1:自选池(信号的原料)

信号来自对"池子里"的股票做分析。维护两个池:

- **核心池(5-10 只)**:你真正持有或密切跟踪的,每周定时分析
- **观察池(轮转)**:筛选器新发现、还没到出手条件的,每两周轮转一次——进池的开始定时观察,连续两期中性的移出(避免池子越攒越大,分析量摊薄)

### 配置 2:定时分析(信号的产线)

- 核心池:每周固定日(周五)收盘后批量跑
- 财报季:临时加密(财报日+1 跑一次)

### 配置 3:提醒(信号的监听)

价格提醒之外,记得看**信号提醒**:当你的持仓股出现方向性判定(尤其 SELL 判定)时,当天要做假设检验(第 15 课步骤 2),不要等周检。

## 🧠 信号中心的三种正确读法

### 读法 1:单条信号 = 研判线索,不是指令

BUY 判定的含义是"当前证据净偏多",不是"明天会涨"。用它的正确方式:点开它的**来源报告**,看判定背后的证据强度和反方论据,再对照你自己的第 16 课复盘框架做决定。

### 读法 2:一批信号 = 你标的池的"天气图"

周末扫一遍本周所有信号:偏多/偏空/中性的比例,就是你池子的天气。全是中性 → 按兵不动是合理输出;多空分歧剧烈 → 波动加大,检查仓位弹性(第 12 课)。

### 读法 3:累计结算 = 引擎的体检报告

每月看结算统计(第 18 课月考):你的核心池上,平台判定的历史胜率与平均 alpha 如何?**这是你该给平台信号多大权重的唯一依据。** 从来不统计,就只能在"全信"和"全不信"之间摆钟。

## ❌ 常见错误

1. **把信号中心当荐票机,见 BUY 就跟**——这条链路的价值在可审计和可统计,不在单条命中率
2. **观察池只进不出**——池子从 10 只涨到 50 只,每只的分析深度必然摊薄;轮转机制必须有退出条件
3. **信号与决策日志两张皮**——按信号(或违背信号)做了操作,要在决策日志里引用信号编号;否则复盘时"当时为什么这么做"永久失传
4. **实盘信号和模拟信号混着用**——账户体系分开记录,统计口径才干净
