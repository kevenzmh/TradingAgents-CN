# 第 29 课:个人交易计划模板——把体系写成合同

> **课时**: 25 分钟 | **难度**: ⭐⭐⭐ 中坚 | **前置**: 第 1-28 课

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,模板不构成投资建议,参数必须换成你自己的,最终决策由你自己负责。

## 🎯 学完后能做什么

- 完成《个人交易计划 v1.0》:资金规则、风格定位、节奏制度、复盘合同——四节一文档
- 理解为什么计划必须落到纸面、必须定期修订、必须留修订记录
- 把前 28 课的工具全部"挂进"计划的对应章节

## 🤔 为什么需要一份"正式"计划

前 28 课你学了一柜子工具,但没有一份计划时,工具的使用取决于当天的心情——熊市缩量时"中长线价值为主",放量普涨三天后"短线题材为主",来回切换,哪套都没走完完整周期。

交易计划的作用:**预先承诺**。它替未来的你在情绪最热/最冷的时候做选择。行为金融的大量研究指向同一结论:预先承诺的规则显著优于临场判断——对新手如此,对老手同样如此。

## 📋 计划模板(四节,填空即成)

### 第一节:资金规则(总纲,最高优先级)

```
1. 总投入资金上限:X 万(占可投资资产 ≤ Y%)
2. 单票上限:总资金的 Z%(第 12 课份数规则的上游)
3. 单行业上限:总资金的 W%
4. 现金下限:任意时刻保留现金 ≥ V%(永远不满仓,第 14 课错误 1 的对冲)
5. 止损铁律:单笔 -8% 或逻辑证伪,先到先执行
```

### 第二节:风格定位(选 1-2 个,写明理由)

```
主风格:【短线 / 中长线 / 混合】
理由:我每周可用研究时间 ___ 小时;我的情绪特点 ___;我的优势领域 ___
副风格(如有):___ ,启用条件:___
明确不做:___(写清你决定放弃的机会类型——这栏比前几栏更重要)
```

相应地,主风格是短线 → 第 20-21 课动线是你的日常;主风格是中长线 → 第 22-23 课周期是你的日常。**混合风格必须写明资金分配**("短线仓 ≤ 20%")。

### 第三节:节奏制度(日历,写死)

| 频率 | 动作 | 平台工具 |
|------|------|---------|
| 每交易日 9:15-9:30 | 盘前计划(短线仓才有) | 筛选+助手(第 20 课) |
| 每周五收盘后 | 核心池定时分析+持仓体检 | 定时分析+助手(第 15 课) |
| 每周日 19:00 | 扫信号天气图+下周计划 | 信号中心(第 26 课) |
| 每月最后一晚 | 月度复盘:可审计度+结算月考 | 复盘(16)+结算(18)+日志(28) |
| 每季末 | 系统体检+计划修订评审 | 回测体检(27) |
| 财报季 | 财报后一周内完成持仓三栏对比 | 财报跟踪(22) |

### 第四节:复盘合同(对"计划本身的维护")

```
1. 本计划每月通读一次,修订需写"修订日期+原因+新旧条款"(第 23 课合同纪律)
2. 连续三周未执行节奏表中的动作 → 冻结新开仓,直到恢复执行(罚则写给自己)
3. 任意单月回撤 > N% → 触发"停机检修":只做复盘不开新仓,直到找到回撤归因
```

## 🧠 什么是"好计划"(三条检验)

1. **可证伪**——"逢低布局高质量发展企业"不可证伪;"分位<30% 且趋势向上时分批买到上限"可证伪
2. **有"不做"清单**——计划的防御力不在进攻条款,在于明确写下的放弃
3. **修订有痕**——计划会被证伪、需要演化,但每一次修订都要能回答"当时为什么改"——修订记录就是计划的决策日志

## ❌ 常见错误

1. **抄别人的参数**——止损 8%、单票 25% 这些数字要按你的资金量、心态承受力自己校准;抄来的参数在压力时刻守不住,守不住等于没有
2. **计划写满进攻,没有罚则**——第四节的三条"自我惩罚"是全计划最有牙齿的部分,删掉它整个计划变成许愿
3. **v1.0 追求完美,迟迟不落笔**——v1.0 的作用是"有",完美是 v5 的事;今晚就写
4. **风格定位写了三种**——个人精力(尤其兼职研究)撑不起多风格并行,选 1-2 个
