# 第 16 课:操作复盘——这笔交易做对了吗

> **课时**: 20 分钟 | **难度**: ⭐⭐ 进阶 | **前置**: 第 10-15 课(持仓阶段)

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 输出的研究报告不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 用平台**操作复盘页**给每笔已平仓交易打分:决策对不对、执行对不对
- 学会区分"结果对"和"过程对"——赚钱的坏决策与亏钱的好决策
- 把复盘结论写成一条可执行规则,而不是一句感想

## 🤔 为什么复盘比研究重要

研究发现机会,复盘提高胜率。多数人研究花 20 小时、复盘花 0 分钟——于是同一个错误可以连犯三年。

复盘回答三个问题:

1. **决策质量**:当初买入的依据是什么?现在回看,那个依据是否合理?
2. **执行质量**:计划是什么?实际怎么做的?偏差在哪?
3. **规则产出**:这笔交易给未来的我留下什么?

## 📍 入口

侧边栏 →「**复盘**」页(`/reports`,操作复盘在报告中心的操作复盘页签),或从持仓页的"已平仓"列表点"复盘"。

## 🖱️ 核心操作

### 操作 1:找到要复盘的交易

操作复盘页列出所有已平仓交易,按平仓时间倒序。找到刚平仓的那笔,点"**开始复盘**"。

### 操作 2:填写复盘四问

平台提供结构化模板,按顺序回答:

1. **买入依据**:我当时为什么买?(从决策日志自动带出,如果你写过;没写过就需要回忆——这也是为什么第 28 课强烈要求写决策日志)
2. **卖出依据**:我为什么卖?
3. **过程评分**:给"决策"和"执行"各打 1-5 分。决策分看"依据当时的信息,该不该做";执行分看"有没有按计划做"。
4. **如果重来**:同样的信息再来一次,我会怎么做?

### 操作 3:让 AI 帮你复盘

不想自己写?在智能助理里说:

> "帮我复盘 XXXXXX 这笔交易"

助手会带出这笔交易的完整生命周期:买入时的分析报告、持有期间的定时报告、卖出时的行情,然后给出结构化复盘建议。**注意:AI 的复盘是素材整理,评分必须你自己打**——把评分外包给 AI,就失去了复盘的意义。

## 🧠 关键概念:结果好坏 ≠ 决策好坏

| | 赚钱 | 亏钱 |
|---|------|------|
| **好决策** | 应得 | 正常成本,持续做 |
| **坏决策** | 运气,最危险 | 学费,改规则 |

复盘最大的敌人是**结果偏差**:赚钱的单子自动被记住"我很英明",亏钱的才想起来翻决策。好决策亏钱是概率游戏的正常成本;坏决策赚钱是最危险的信号——它会强化错误习惯,让下次亏得更多。

**打分只看当时的依据,不看涨跌。**

## 📊 平台的结算数据怎么看

操作复盘页每笔交易带**决策结算**信息(第 18 课详讲):信号方向、判定后 N 日实际涨跌、相对基准的 alpha。看复盘时把两段分开:

- **结算数据**告诉你"市场的答案"——它涨还是跌了
- **你的评分**告诉你"你的答案"——过程对不对

两段都对:能力确认。结算对、评分错:运气单,别太自信。结算错、评分对:正常成本。两段都错:进错误清单(第 14 课)。

## ❌ 常见错误

1. **只复盘亏钱的**——赚钱的单子更需要复盘,尤其是"坏决策赚钱"型
2. **复盘写成感想**——"下次要注意风险"不可执行;要写成"单票回撤超 10% 时先减半仓"(可执行)
3. **拖到忘了才复盘**——平仓当天或次日做,记忆和情绪最完整

## ✅ 自测清单

- [ ] 复盘过至少一笔已平仓交易(纸质或平台)
- [ ] 给决策和执行分别打过 1-5 分
- [ ] 写出过一条"可执行规则"而非感想
- [ ] 能说出一个自己"坏决策但赚钱"的案例
