# 第 12 课:加减仓决策——把"买卖多少"变成规则

> **课时**: 20 分钟 | **难度**: ⭐⭐⭐ 中坚 | **前置**: 第 11 课

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 输出的研究报告不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 学会加减仓的**规则化方法**(仓位份数法、金字塔法、条件加减仓)
- 用 AI 分析结论(估值/风险/信号)作为加减仓的触发条件
- 避免"满仓梭哈"和"越跌越补"这两大经典错误

## 🤔 为什么"买卖"容易,"买卖多少"很难?

建仓之后的每个加仓/减仓决策都要同时回答两个问题:**方向**(加还是减)和**数量**(多少)。散户最常见的三种失衡:

| 症状 | 本质 |
|------|------|
| 一把梭满仓 | 没有仓位概念,把"看好"等同于"全押" |
| 越跌越补,补到重仓套牢 | 把"摊成本"当纪律——下跌中无证据地放大暴露 |
| 赚 5% 就跑、亏 30% 死扛 | 没有"基于理由的退出规则",盈亏归因全错 |

解法:在建仓**之前**就把加减仓规则写好——这是"规则化交易"和"随感觉交易"的分水岭。

## 🧠 方法一:仓位份数法(推荐入门)

把单只股票的**目标总仓位**拆成 3 份:

- **第 1 份(试探仓,40%)**:研究结论成立时建仓
- **第 2 份(确认仓,40%)**:结论被后续走势/业绩**验证**后加仓(如:季报确认逻辑、放量突破关键位)
- **第 3 份(机动仓,20%)**:留给超预期机会,或干脆不用

**配套规则**:
- 只有"确认仓"的触发条件达成才允许加第 2 份
- 试探仓亏损 >15% 时无条件停止加仓,重新审视研究结论
- 单票仓位达到目标后的进一步上涨**不追加**——追加的理由必须来自新信息,不是"它一直在涨"

## 🧠 方法二:条件加减仓表(把 AI 结论翻译成动作)

建仓时写一张表(存进决策日志,第 28 课):

| 条件(AI 可以判断) | 动作 |
|---------------------|------|
| 季报营收/利润符合买入逻辑 | 加确认仓 |
| 估值分位升破历史 80% | 减 1/2 仓 |
| 跌破买入逻辑的核心假设(如现金流背离恶化) | 清仓 |
| 亏损超 20% 且逻辑未变 | 持有并写持有理由 |
| 亏损超 15% 且逻辑已破坏 | 立即清仓 |

这张表的两大价值:**盘中不用判断**(条件到了照做)和**事后可复盘**(第 16 课对照执行)。

## 🖱️ 用平台辅助执行

1. 信号中心:AI 分析若产出审慎(看空)信号,对照你的条件表——它就是"逻辑破坏"的独立佐证
2. 个股分析报告:每份报告的"估值分位"和"核心风险"节,就是你的条件输入源
3. 止盈止损提醒:在个股详情或 ETF 详情页设置价格提醒,条件触发时平台通知你(免盯盘)
4. 决策日志:每次加减仓**写一句执行依据**——"触发条件 B:分位破 80%,计划减半仓"

## ⚠️ 平台当前的能力边界(2026-11)

社区版的信号链路是 signal_only:AI 产出信号后**停在人机确认**,不自动下单。加减仓的执行永远由你手动完成(模拟盘记一笔,或券商 App 操作),平台负责给你触发条件与依据。这是有意设计——把"扣扳机"留在人手里。

## ❌ 常见错误

1. **把"看好"当仓位**——看好是方向观点,仓位管理是独立维度;看错时仓位决定生死
2. **无条件的左侧加仓**——"跌了就补"没有证据支持,唯一正当的加仓理由是"确认条件达成"
3. **规则天天改**——条件表一周一改等于没有规则。允许每月复盘时修订一次
