# 第 14 课:持仓阶段的常见错误——一年亏损的解剖图

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,AI 输出的研究报告不构成投资建议,最终决策由你自己负责。

- 对照七大持仓错误自查
- 理解每一类错误的成因和平台层面的对冲手段

## 🧠 七大持仓错误

### 错误 1:满仓单票(研究越自信,坑越深)

**场景**:研究 3 周觉得某股十拿九稳,all in。
**成因**:把"研究置信度"等同于"仓位权重"——但研究置信度本身不可靠(AI 或人都是)。
**对冲**:单票上限(如 ≤25%),再看好也拆份建仓(第 12 课)。
**平台提示**:持仓研究报告会在你单票超 30% 时点名集中度风险。

### 错误 2:补仓摊成本(下跌中的确认偏误)

**场景**:跌 10% 补一成,再跌再补,最后满仓套 30%。
**成因**:每笔补仓都强化了"我是对的"这个心理需求,却从不问"下跌有没有揭示买入逻辑的错误"。
**对冲**:每笔加仓都要有独立的确认证据(逻辑确认、量价确认、财务确认),不是价格确认。亏损超 15% 时禁止加仓——先用决策日志写下"如果今天空仓,我会买它吗?"

### 错误 3:亏了死扛、赚了拿不住(处置效应)

**场景**:-20% 时说"价值投资不止损",+8% 时说"见好就收"。
**成因**:盈亏的痛感不对称。结果:盈利单平均小赚,亏损单平均巨亏——胜率高也亏钱。
**对冲**:进出规则在第 13 课的框架下设定,组合层面看**平均盈利/平均亏损比**(操作复盘页有统计)。

### 错误 4:频繁交易(把"勤奋"当"专业")

**场景**:每天盯着信号与分析,一周 3-5 单。
**成因**:交易行为本身会成瘾;且短期波动是噪音,越频繁越接近负和博弈(手续费+滑点)。
**对冲**:决策窗口固定(每周 1 次,第 8 课),其余时间不打开交易界面。

### 错误 5:仓位风格漂移(报告越读越乱)

**场景**:本来做低波动防御,某天读到一篇"科技股风口"研究,追高买入。
**成因**:研究是拿来"证实"而非"证伪"的;风格漂移通常发生在组合浮亏、情绪想扳回来的时刻。
**对冲**:每月对照持仓研究的风格暴露诊断"我现在的组合还是我当初想做的组合吗?"

### 错误 6:风险口口声声,规则一张没有

**场景**:"我有止损纪律"——但止损位记在脑子里,没写、没设提醒、触发后可讨论。
**对冲**:规则必须**外化**:写进决策日志+ 设平台价格提醒。外化的规则才会被执行。

### 错误 7:赚了归自己、亏了骂 AI

**场景**:盈利的单子是"我英明决断",亏损的都是"这破 AI 报告误导我"。
**成因**:自利归因偏差。它阻止你从错误中学习的速度,比错误本身伤害更大。
**对冲**:操作复盘(第 16 课)的模板要求**先给自己的判断打分,然后才评估工具质量**——工具的问题(比如某数据源缺数据)记录下来反馈到下一阶段的使用习惯。

## 🔁 错误管理的平台抓手

错误链的正确管理方式(而不是"下次小心"):

```
犯了错 → 写进复盘 → 写成规则 → 外化为平台设置 → 下个循环开始
```

例如发现自己在 $XX$ 题材单杀中满仓回撤 25% → 复盘记录 → 规则"单行业不超过 40%" → 设置行业集中度月检(配合持仓研究报告) → 下月发现白酒合计 42% 就强制降至 40% 以下。

错误不可怕,重复同一个错误才可怕。
