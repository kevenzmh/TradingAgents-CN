# 第 23 课:中长线实战——估值修复与业绩跟踪

> **课时**: 30 分钟 | **难度**: ⭐⭐⭐ 中坚 | **前置**: 第 22 课

> ⚠️ **风险提示**:本课程内容仅为平台功能教学,案例为教学示意,不构成投资建议,最终决策由你自己负责。

## 🎯 学完后能做什么

- 走完一个中长线周期的标准动作:深研定案 → 分批建仓 → 季度财报跟踪 → 条件出场
- 学会"估值修复"类机会的完整逻辑链与反方压力测试
- 掌握"买前定合同"——把卖出条件在买入当天写死

## 📋 周期五步(时间尺度:月-季)

### 第 1 步:深研定案(第 0 周)

在筛选(低分位 + 基本面无硬伤)出候选后,跑 **5 级深度 + 多情景辩论**,产出你的"投资备忘录",只有三行:

1. **买入逻辑**(一句话):"分红率 60%+的公用事业股,盈利中枢稳定,PE(TTM) 分位 12%,估值修复到行业中位水平即有 25% 空间"
2. **最强反方**(辩论里空方观点):"电价市场化改革可能压低盈利中枢,低估值是市场对改革风险的定价"
3. **可证伪条件**(什么情况下我错了):"若下一年度电价合同重签价降超 5%,逻辑作废"

### 第 2 步:定合同(第 0 周,买入前)

**买入当天,卖出条件必须已写死**(写进决策日志 + 第 12 课条件表):

- 逻辑证伪(上述可证伪条件触发)→ 无条件出局,不看价格
- 估值到位:PE(TTM) 分位回到 60% 上下 → 分两批了结
- 时间止损:3 个财报季内逻辑无验证迹象 → 退出(资金效率也是收益的一部分)

### 第 3 步:分批建仓(第 1-3 周)

第 12 课的份数规则:先 1/3 仓;回调 5% 且逻辑无新变化 → 第 2 份;**不许因为"急着上车"一次打满**。每一笔的买入价记入决策日志。

### 第 4 步:季度财报跟踪(每季 1 次)

财报出来后(平台周日自动同步财务数据 → 报告可用),问助手对比(第 22 课第 3 层),填三栏一行:

| 财报指标 | 买入时 | 本季 | 判定 |
|---------|--------|------|------|
| 盈利(扣非) | 基准 | 变化 ±% | 强化/无变化/削弱 |
| 分红率/现金流 | 基准 | 变化 | 强化/无变化/削弱 |
| 行业/电价(逻辑要素) | 基准 | 变化 | 强化/无变化/削弱 |

三栏中**逻辑要素**权重最大——盈利波动一季可以是噪音,逻辑要素恶化是结构信号。

### 第 5 步:执行出场

出场只有两个来源:**合同里写过的,或合同需要修订的**。合同没写到的情况(例:突发并购公告)= 逻辑输入变了 → 重新走一遍第 1 步对比"新世界 vs 老合同",不可临场直接决定。

## 🧠 完整案例演示(教学示意)

> **第 0 周**:筛选出某水电股,PE(TTM) 分位 15%,股息率 4.2%。深研后备忘录:逻辑=现金流机器+利率下行环境估值修复;反方=来水偏枯年份盈利波动;可证伪=连续两个枯水年份。
> **第 2 周**:25.4 买入 1/3 仓。
> **第 5 周**:回调至 24.1(-5%),无新信息 → 第 2 份,成本摊至 24.7。
> **第 2 季财报**:盈利 +8%,来水偏丰,逻辑强化 → 第 3 份,停止加仓(满仓即无余地)。
> **第 4 季**:PE 分位回到 55%,触发第一批了结条件 → 卖 1/2;分位 62% → 清仓。全程 11 个月,+21%(未计分红)。
> **复盘**:决策 4.5 分(合同在先,两批了结按计划);执行 5 分(无临场改约)。经验入库:"公用事业的估值修复,加仓节奏比选股更影响最终收益"。

## 🧠 中长线的"慢纪律"和短线的"快纪律"对比

| | 短线 | 中长线 |
|---|------|--------|
| 纪律的类型 | 执行纪律(触发即做) | 合同纪律(写死不为动) |
| 最大的敌人 | 情绪(追涨/临场改止损) | 无聊(持有期想找事做) |
| 复盘重点 | 执行偏差 | 逻辑维护(每季一小验,合同学期一大验) |
| 平台核心工具 | 筛选+行情+提醒 | 深研+定时分析+财报同步 |

**中长线最常犯的错不是买错,是"持有期手痒"——加仓没条件、移AMAGE 没依据、忘了自己订的合同。** 合同的存在就是为了让第 11 个月的你还受第 0 周的你约束。

## ❌ 常见错误

1. **备忘录不写可证伪条件**——没有证伪条款的逻辑永远"成立",你永远没有卖出理由
2. **财报跟踪变成"看盈利涨跌"**——盈利数字波动≠逻辑变化,先看逻辑要素再看盈利
3. **深研报告存 而不读反方**——辩论环节的空方论据是整份报告里最值钱的部分,它替你预演了最坏情形
4. **合同修订无记录**——需要修订合同时,必须写"修订日期+新证据+旧条款",否则你会"已在逐步放宽而不自知"
